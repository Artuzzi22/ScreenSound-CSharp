# Screen Sound

Aplicação de console desenvolvida em C# durante meus estudos de desenvolvimento e programação na Alura.

O projeto permite registrar bandas, visualizar bandas cadastradas, adicionar avaliações e consultar a média das avaliações de cada banda.

## Funcionalidades

- Registrar novas bandas
- Exibir todas as bandas cadastradas
- Avaliar uma banda
- Calcular a média das avaliações de uma banda
- Navegação através de um menu interativo
- Validação da existência da banda antes de realizar avaliações

## Tecnologias utilizadas

- C#
- .NET
- Visual Studio

## Como executar

1. Clone este repositório.
2. Abra o arquivo `PrimeiroProjeto.csproj` no Visual Studio.
3. Execute a aplicação.
4. Utilize o menu apresentado no console para interagir com o programa.
